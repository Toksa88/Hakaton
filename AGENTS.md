## Що ми робимо
Хакатон, тема **Harmonization of MODIS and VIIRS Hot Spots**. Дедлайн ~15.11.2026.
Веб-додаток, що узгоджує активні осередки пожеж MODIS і VIIRS (NASA FIRMS) у
**календар активності горіння** для вибраної зони інтересу: історичні патерни,
незвичайні умови (аномалії), критичні періоди. Користувачі — служби раннього
попередження, вчені, землекористувачі. Регіон за замовчуванням — Україна.

## Стек і структура
Python 3.11+, Streamlit (UI), pandas, plotly. Без окремої БД — дані з CSV, кеш у parquet.
```
app.py                 Streamlit-додаток (усі вкладки)
firecal/load.py        CSV FIRMS -> єдина схема (lat, lon, date, sensor, conf_class, ...)
firecal/harmonize.py   гармонізація: сітка -> пожежо-клітинко-дні -> union -> калібрування k
firecal/analytics.py   календар, норма, аномалії (робастний z), критичні періоди
firecal/regions.py     зони інтересу (bbox)
scripts/               генератор тестових даних, smoke-тест додатку
tests/                 pytest
data/raw/              сирі CSV (не в git)
```

## Методика (не ламай без обговорення)
1. Достовірність: MODIS <30 low, 30–79 nominal, ≥80 high; VIIRS l/n/h. Лишаємо `type == 0`.
2. Точки -> клітинки сітки (дефолт 0.1°). Одиниця — пожежо-клітинко-день.
3. Union MODIS ∪ VIIRS для періоду з VIIRS.
4. До VIIRS (до 2012): MODIS × k[місяць], k = union/MODIS у період перекриття.
