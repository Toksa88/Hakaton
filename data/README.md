## Як скачати справжні дані для України
1. Відкрити https://firms.modaps.eosdis.nasa.gov/country/
2. Країна: **Ukraine**. Скачати CSV за кожен рік для двох джерел:
   * **MODIS** (2000/2001 – сьогодні) — `modis_YYYY_Ukraine.csv`
   * **VIIRS S-NPP** (2012 – сьогодні) — `viirs-snpp_YYYY_Ukraine.csv`
3. Покласти всі CSV у `data/raw/`. Назви файлів не важливі — додаток сам визначає датчик за колонками.
4. Видалити тестові `SAMPLE_*.csv`, перезапустити `streamlit run app.py`.

Альтернатива — API з ключем (MAP_KEY безкоштовний: https://firms.modaps.eosdis.nasa.gov/api/map_key/).
