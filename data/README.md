```
data/
  raw/     <- сирі CSV з NASA FIRMS (НЕ комітяться в git, кожен качає сам — вони великі)
  team/    <- ваші файли: нотатки, аналіз, ноутбуки, маленькі CSV, скріншоти для презентації
  cache/   <- автоматичний кеш додатку (не чіпати, не комітиться)
  deploy/  <- ukraine.parquet: усі дані для сервера (ЛЕЖИТЬ у git; оновлює scripts/build_deploy_data.py)
```
Якщо в `raw/` немає жодного CSV, додаток бере дані з `deploy/ukraine.parquet` — тому одразу після
`git clone` (і на сервері) він уже показує справжню Україну без завантаження.

## Як скачати справжні дані для України

**Найпростіше — одна команда** (з папки проєкту, кілька хвилин, ~145 МБ):
```
.venv/Scripts/python scripts/download_firms.py
```
Скрипт сам качає MODIS 2000–2025 і VIIRS 2012–2025 у `data/raw/` і видаляє `SAMPLE_*.csv`.
Обірвалось — запусти ще раз, докачає лише відсутнє.

Те саме вручну:
1. Відкрити https://firms.modaps.eosdis.nasa.gov/country/
2. Країна: **Ukraine**. Скачати CSV за кожен рік для двох джерел:
   * **MODIS** (2000/2001 – сьогодні) — `modis_YYYY_Ukraine.csv`
   * **VIIRS S-NPP** (2012 – сьогодні) — `viirs-snpp_YYYY_Ukraine.csv`
3. Покласти всі CSV у `data/raw/`. Назви файлів не важливі — додаток сам визначає датчик за колонками.
4. Видалити тестові `SAMPLE_*.csv`, перезапустити `streamlit run app.py`.

Альтернатива — API з ключем (MAP_KEY безкоштовний: https://firms.modaps.eosdis.nasa.gov/api/map_key/).
